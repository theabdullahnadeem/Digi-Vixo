# Digivixo — Project Overview

## What This Is
A complete Next.js rebuild of digivixo.com — a premium AI calling agent service targeting US/UK CPA firms and accounting practices.

## Design References
- **abdullahpk.site** — Preloader pattern, smooth entry animations
- **k72.ca** — Dark luxury aesthetic, bold typography, editorial layout
- **apple.com** — Scroll-driven storytelling, product clarity, refined spacing

## Tech Stack
```
Next.js 16 (App Router)
GSAP + ScrollTrigger (premium animations)
Lenis (smooth scroll)
Lottie.js (animated icons/illustrations)
Tailwind CSS (utility styling)
TypeScript
Framer Motion (micro-interactions, optional layer)
```

## Design Direction
**Theme:** Dark luxury / refined minimal
**Palette:** Near-black background (#080808), warm white text (#F5F0E8), gold accent (#C9A84C)
**Mood:** Like a premium financial consultancy — not a tech startup, not an agency. Trustworthy, expensive, precise.
**Typography:** Display — Cormorant Garamond (editorial, luxury). Body — Neue Montreal or DM Sans.

## Pages
1. `/` — Homepage (main landing, full scroll experience)
2. `/case-study` — Anonymous case study with metrics
3. `/contact` — Booking page (Calendly embed)

## Key Conversion Goals
1. Establish credibility in 3 seconds
2. Communicate the single result: missed calls → revenue recovered
3. Get a Calendly booking
